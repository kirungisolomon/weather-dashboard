# WeatherFlow Dashboard

A simple static weather intelligence dashboard built with HTML, CSS, and JavaScript.

## Project Contents

- `index.html` contains the dashboard layout.
- `styles.css` contains styling and responsive layout rules.
- `script.js` contains city search and update behavior.

## Local Run

Open `index.html` in a browser, or serve the directory locally:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.
